# 공통 문체·디자인 점검

쓰기 전에 한 번, 다 쓰고 나서 한 번 본다. 대괄호 숫자는 `sources.md` 출처 번호다.

## 문체

- 답을 먼저 쓴다. 제목에는 주제가 아니라 결론을 쓴다. [1]
- 쉬운 한국어 평서형(`~다`). 한 문장에 한 생각, 능동형. 문단은 1~3문장. [1]
- 한 개념에는 한 용어만 쓰고 끝까지 같은 이름으로 부른다. 이름은 읽는 사람이 아는 말로 짓는다. [1][5]
- 비유, 군말, 느낌표 제목을 쓰지 않는다. `=`, `→`, `+`, `★`로 조사를 대신하지 않는다.
- "높음", "많음" 대신 단위가 있는 값을 쓴다. 확인하지 못한 사실은 그렇게 표시한다. [7][1][2]
- 그림을 설명하는 문장은 그림의 라벨이나 캡션으로 옮긴다. 본문은 그림이 말하지 않는 것을 쓴다. [1]
- 오류나 실패를 쓸 때는 원인과 고치는 법을 쓴다. 사과하지 않는다. [5]

## AI가 만든 티가 나는 기본값 피하기

- 쓰지 않는 것: 크림 배경에 테라코타 강조, 검정 배경에 형광 강조, 신문형 hairline과 직각 모서리 일색, 같은 둥근 카드와 회색 그림자의 반복. [5]
- 쓰지 않는 것: 모든 제목 위의 대문자 작은 라벨(eyebrow), `A · B · C`식 메타 문자열 남발, "단어 — 조각" 라벨, 줄 끝마다 붙은 →. [5]
- 제목에서 한 단어만 색으로 강조하지 않는다. 01/02/03 번호는 실제 순서가 있을 때만. [5][1]
- 섹션마다 들어오는 애니메이션, 모든 카드의 hover 효과, 그라디언트 글자, 네온, 보라 강조를 쓰지 않는다. [5][1]
- 그림자와 10px를 넘는 둥근 모서리를 쓰지 않는다. 카드 안에 카드를 넣지 않는다. [7][5]
- 바탕은 약 90%를 중립으로 두고, 신호색은 한 곳에만. [5][1]
- 이 스킬의 결정: `.verdict`의 왼쪽 강조 테두리와 상태 chip은 기존 vault 보고서와 맞추려고 쓴다. 구조만 가져오고 장식은 늘리지 않는다.

## 접근성·반응형 하한

- 폰까지 반응형. 390px에서 페이지 가로 스크롤 없음. 포커스 표시, 움직임 줄이기 존중. [5]
- 본문 15px(기존 vault 보고서와 맞춤), 줄 간격 1.5 이상, 줄 길이 65~75자 안팎. 보조 글은 12px 아래로 내리지 않는다. [1]
- 대비: 본문 4.5:1, 뜻이 있는 테두리·아이콘 3:1. chip은 두 테마에서 모두 AA. 흐린 글자는 opacity가 아니라 `--muted` 토큰으로. [1][2]
- 색만으로 뜻을 전하지 않는다. 글자, 모양, 무늬를 함께. [1][4][7]
- SVG에는 viewBox, 그림에는 width·height. [1]

## 클래스 이름

- 부품 클래스에는 부품 앞머리를 붙인다(`.g-`, `.hb-`, `.ev-`, `.pair-`, `.ft-`, `.plan-band`). 상태 수식어(`pass`, `hold`, `block`, `plan`, `info`, `done`, `fix`, `key`)와 같은 이름을 단독 부품 클래스로 쓰지 않는다.
- 2026-11-03 첫 검증에서 두 번 부딪혔다. 원인 → 대책의 `.fix`가 타임라인의 `.ev.fix`에 배경을 깔았고, 일정 띠의 `.plan { display: grid }`가 상태 chip `.chip.plan`을 grid로 펼쳤다.

## 넘침 점검 목록

- grid·flex 자식에 `min-width: 0`. 긴 경로·ID에는 `overflow-wrap: anywhere`(`body`에 이미 있다). [1]
- 고정폭 열, `overflow: hidden`, `white-space: nowrap`이 잘라 먹는 곳을 찾는다. 표 머리의 고정폭(예: 180px, 300px)은 390px에서 넘친다. [2]
- 표, 그림, 코드는 각자 `overflow-x: auto` 틀(`.table-wrap`, `.scroll-x`, `.term pre`) 안에서만 스크롤한다. body가 가로로 스크롤되면 안 된다. [2]
- 코드 블록은 `white-space: pre`(가로 스크롤) 또는 `pre-wrap`. [9]
- `li`에 `display:flex`로 표식을 달지 않는다. 나란한 패널은 좁은 화면에서 한 열로. [1]
- 상태 JSON 안의 `<`는 `<`. [2]
- 다 쓴 뒤 `scripts/check.mjs`를 돌리고, 찍힌 그림을 직접 연다.
